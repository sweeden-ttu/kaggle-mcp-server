# Expert Definitions

This directory contains exported expert JSON definitions generated by the MLSysEng MoE system.

Each expert corresponds to a chapter from the ML Principles PDFs and includes:
- **capabilities**: What the expert can do
- **skills**: Kaggle skill paths the expert recommends
- **strategy**: Step-by-step approach (Baseline → EDA → Feature Engineering → Model Selection → Submit)
- **formula**: Mathematical objective function
- **loop_config**: State convergence loop parameters

Experts are auto-generated by `extract-knowledge` and can be manually edited here.
