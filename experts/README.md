# Expert Definitions

This directory stores JSON definitions for chapter-based experts.
Experts are auto-generated by the `ExpertRegistry` from indexed ML Principles chapters.

Each expert file contains:
- `expert_name`: Human-readable name
- `slug`: URL-safe identifier
- `capabilities`: What this expert can do
- `skills`: Kaggle skill paths to activate
- `strategy`: Step-by-step approach
- `formula`: Optimization objective and metrics
- `loop_config`: Convergence loop parameters
